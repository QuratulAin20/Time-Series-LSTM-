# Temperature Prediction with LSTM

## 📊 Project Overview
This project implements a Streamlit application that utilizes a pre-trained LSTM (Long Short-Term Memory) model to predict temperature based on historical data. Users can upload their CSV files containing temperature data, and the app will generate predictions.

## 🛠️ Features
- Upload CSV files to test the LSTM model.
- View and analyze the predicted temperature values.
- Visualize predictions with a plot option.

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Streamlit
- TensorFlow
- NumPy
- Pandas
- Matplotlib
